# Healing Cascade

> The temporal sequence of regenerative events following Spring Leaf construct placement.

---

## Timeline

| Days | Phase | Description |
|------|-------|-------------|
| 0-3 | **Inflammation** | Controlled inflammatory response, neutrophil/macrophage recruitment |
| 3-7 | **Neural Ingrowth** | NGF-mediated sensory fiber extension into construct |
| 7-14 | **Vascularization** | PDGF-BB drives angiogenesis along neural tracks |
| 14-21 | **PDL Formation** | BMP-7 directs fibroblast differentiation, fiber alignment begins |
| 21-28 | **Maturation** | BDNF supports neural survival, cementum formation initiates |
| 28+ | **Remodeling** | Functional fiber insertion, proprioceptive function restored |
