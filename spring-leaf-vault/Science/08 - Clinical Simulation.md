# Clinical Simulation

> Computational modeling of Spring Leaf construct performance in clinical scenarios.

---

## Defect Types Modeled

| Type | Configurations |
|------|---------------|
| Intrabony Defects | 1-wall, 2-wall, 3-wall |
| Furcation Defects | Class I, II, III involvement |
| Recession Defects | Miller Class I-IV |

## Predicted Outcomes

| Metric | Result |
|--------|--------|
| Clinical Attachment Level (CAL) | **+4.2 mm** |
| Probing Depth Reduction | **-5.1 mm** |
| Bone Fill | **78%** |

## Model Parameters

| Parameter | Value |
|-----------|-------|
| Diffusion coefficient (growth factors) | 1.2 x 10^-7 cm2/s |
| Cell migration speed | 15 um/hr |
| Hydrogel degradation rate | 3.5%/day |
| Simulation duration | 28 days |
